# 网易云自动签到

这个仓库通过 GitHub Actions 定时执行网易云每日签到，并提交推荐歌单中的播放记录。

## 配置

1. Fork 本仓库并打开自己仓库的 **Settings > Secrets and variables > Actions**。
2. 新建两个 Repository secret：
   - `USER`：手机号；多个账号用 `#` 分隔。
   - `PWD`：对应密码；多个密码按相同顺序用 `#` 分隔。
   - `COOKIE`（可选）：网易云网页端导出的完整 Cookie；使用 Cookie 时仍需为每个账号提供一个占位密码，多个 Cookie 用 `#` 分隔。
3. 在 **Actions** 页面手动运行 `网易云签到`，或等待定时任务。

定时任务使用 UTC `14:00` 和 `22:00`，对应中国标准时间 `22:00` 和次日 `06:00`。也可以通过 `workflow_dispatch` 手动运行。

## 注意

- 密码中不能包含用于分隔账号的 `#`。
- 如果手机号密码登录返回 8821，建议在网易云网页端完成验证后导出 Cookie，保存为 `COOKIE` Secret。Cookie 与账号一一对应，也用 `#` 分隔。
- 网易云接口或账号风控策略变化时，脚本可能失效。
- 该脚本提交的是播放记录，不代表真实播放；请自行评估账号风险和平台规则。
